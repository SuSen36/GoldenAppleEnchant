# Golden Apple Enchantments

为金苹果添加多种独特附魔。

## 模组功能

### 金苹果附魔

| 附魔名称 | 效果说明 |
|----------|----------|
| **注魔** (Infusing) | 将普通金苹果转化为附魔金苹果 |
| **充分吸收** (Amplification) | 提升附魔金苹果的药水效果持续时间和等级 |
| **精力充沛** (Energetic) | 食用附魔金苹果时获得力量、速度和急迫效果 |
| **金闪闪** (Glint) | 食用附魔金苹果时获得夜视和发光效果 |
| **丰食** (Bountiful) | 增加附魔金苹果恢复的饥饿值和饱和度 |
| **伊甸园之殇** (Bane of Eden) | 食用附魔金苹果时受到饥饿和反胃效果（诅咒附魔） |

### 成就

- **浮光跃金** - 附魔一个金苹果
- **君临天下** - 吃下附魔后的金苹果

### 使用方法

1. 将**金苹果**放入附魔台，附魔**注魔**后会转换为**附魔金苹果**
2. 将**附魔金苹果**可附魔其余的附魔
3. 食用附魔后的金苹果，体验独特效果！
